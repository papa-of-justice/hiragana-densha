# ひらがな でんしゃ

3歳前後の子ども向けの、ひらがなと電車の名前をおぼえるアプリです。無料・広告なし・登録不要で、ブラウザで遊べます。鉄道会社の公式アプリではありません。

## データの保存について

スタンプ・集めたカード・入力した名前は、使っている端末のブラウザの中(localStorage)だけに保存されます。外部には送信されません。
